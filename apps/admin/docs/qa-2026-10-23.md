# Configuration saving — October 23, 2026

Save updates the existing available configuration by ID, including configurations selected in the live A/B test. It changes all editable settings without inserting a new configuration, changing the active IDs, or retiring the old value. Retirement remains explicit; retired rows cannot be overwritten and can be reused only under a unique name.

A PostgreSQL unique expression index reserves names across current and retired configurations. Case and whitespace differences are ignored. Inserts and renames use the same constraint, including concurrent requests, and the form shows a specific duplicate-name error.

Each run captures its configuration inputs when claimed. Renaming or editing a configuration later cannot alter that run's saved instructions or revealed method labels. Arena votes continue to accumulate by configuration ID across edits; the overview and Prompt Lab disclose this behavior. To separate experiments in the leaderboard, create a separately named configuration and retire the old one manually.
