# Admin operations

The admin app supports the gallery and Funny Lab through Overview, Content, Image library, Activity, Workflow, Examples, and People & access.

Read the [shared operational contracts](../../web/docs/gallery/system.md) for publication snapshots, moderation, image access, generation revisions, and verification. [Setup](../../web/docs/setup.md) documents credentials and OAuth callbacks.

Account → Admin in the user app links here. Every administrative data operation still requires the exact allowlist. Server credentials remain private; the client cannot choose arbitrary providers or API endpoints.
