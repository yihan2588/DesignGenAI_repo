# Source-to-caption handoff audit — October 16, 2026

The previous 1,003-record Supabase reruns completed but produced no qualifying retrieval-backed captions for the two supplied images. Increasing corpus quantity did not address the main failures: repeated topical queries, weak source-to-turn mappings, and an early admission gate that prevented the writer from repairing usable drafts.

The old graph repeated the full scene and conflict at every hop while ignoring node relations. It preferentially found jokes sharing objects such as sofas, ceilings and animals. The revised graph searches each node’s source-independent expectation/turn probe alongside its root visual observation. The existing bounds remain: two targets, three hops, eight queries, twenty distinct sources. The index and corpus are unchanged. A four-record spot-check found each stored vector aligned with a fresh embedding in all three fields; this is a limited integrity check, not an all-corpus semantic audit.

The old source planner could either admit a vague theme or reject a useful structure without trying a caption. A coffee joke’s practical lesson became generic furniture danger; an animal’s anticipatory escape became generic transport. Making the planner stricter alone then caused false negatives: it rejected an athletic-renaming prototype because the photo itself did not depict the punchline or motive. An attempted extra repair call repeated the same advisory rejection.

The final flow is **prototype → advisory critique → caption rewrite → final source admission**:

- The adapter must attempt two concrete source-based prototypes, with original setup/turn quotations, mapped caption spans and a visible/fictional framing. These are hypotheses, not successful transfers.
- The reviewer reads the originals and critiques those drafts. Its grade is advisory. It can suggest a better source, but a grade-1 judgment does not prevent the writer from repairing a structurally valid prototype.
- Before writing, deterministic checks enforce source IDs, exact original quotes, detail references, and wordplay classification/lexical prerequisites. Invalid hypotheses are excluded. Compact demonstrations keep original text and available prerequisites within the existing 1,500-byte budget.
- The writer sees valid hypotheses and critique, and must attempt at least two source adaptations among five candidates. It can rewrite a bad seed instead of being forced to preserve it verbatim. Attempts are not counted as success.
- The independent image-conditioned final judge reads the actual captions and original jokes. Every supported source needs distinct exact caption spans carrying its setup and distinctive twist, within an application quoting the entire caption. Punchline-only applications are rejected. The final filter retains source checks, exact applications, lexical prerequisites, copy checks and physical grounding checks. Exposure or an early planner score never counts as a verified contribution.

Grounding now separates physical evidence from explicitly fictional caption framing. Objects and depicted actions must remain accurate. A caption can supply imaginary dialogue, motives, a hypothetical social situation or toy roleplay while retaining an image-specific physical anchor. A source’s original spouse, workplace or conversation need not appear literally when their functions are clearly replaced. Generic unrelated storytelling, a guessed device identity or an actually invented physical fall still fails. Self-contained visual details, narrow equivalents such as sofa/couch, and noun-phrase variants such as “sofa cushions” / “cushions of the sofa” prevent avoidable wording rejections. The deterministic coverage check preserves subject/object sides around actions and spatial relations; it supplements the image-conditioned semantic judge rather than proving entailment.

The lightweight model continued to produce weak mappings or overly literal rejections. Earlier calls reported zero thinking tokens. Google's [Gemini thinking guidance](https://ai.google.dev/gemini-api/docs/gemini-3#thinking_level) documents Flash-Lite's minimal default. High-thinking experiments exhausted 4,096- and 8,192-token ceilings, so final semantic stages use explicit medium thinking with an 8,192-token ceiling. The baseline, description association, source adapter/reviewer, writer and judge use Gemini 3.8 Flash; visual and image-association drafts use Flash-Lite. [Model capabilities](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash) and [current rates](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.8-flash) were verified. Each call records its actual model, generation configuration and rate estimate. Flash pricing fails closed in 2027 pending review.

The final reviewed pipeline uses nine normal calls, leaving one attempt for schema repair or retry within the ten-attempt cap. Strong-model requests have a 90-second timeout within the existing 300-second run deadline; Flash-Lite requests retain 45 seconds. Forward migrations preserve capability, lease, size and permission guards while allowing the source-review checkpoint and the historical source-revision diagnostic. The final implementation incorporates critique-driven rewriting in the existing writer call; it does not make that extra revision call. Hosted generation, ingestion and production corpus approval remain disabled.
